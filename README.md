# cre-bounty

Entry for the BLI Legal Tech Hackathon 2 on DoraHacks, targeting two bounties:

- Chainlink: Best workflow with CRE
- RYO-CHAN: Autonomous Agents

The idea is still being finalised. See [PLAN.md](./PLAN.md) for the plan, architecture and milestones.

## Stack

- Next.js (App Router, TypeScript, Tailwind)
- Chainlink Runtime Environment (CRE) workflow
- LLM for evidence analysis

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
